# John Matthews Recording Studio

A custom, responsive one-page website for John Matthews' recording studio.

## Preview

From this folder, run:

```bash
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080/`.

## Files

- `index.html` — client-facing page structure and copy
- `styles.css` — complete responsive art direction and motion
- `script.js` — mobile menu, viewport reveals, video sound control, and static form success state
- `Hills_East_Recording.mp4` — looping hero studio video
- `assets/hills-east-poster.jpg` — generated video poster for fast, stable first paint

## Design direction

Warm editorial analog: deep espresso, recording-light amber, paper stock neutrals, precision mono labels, and high-contrast display typography. The hero artwork is an original inline SVG inspired by reel-to-reel machines and mixing consoles, so it remains sharp at every viewport without relying on stock photography.
